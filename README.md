# Titanic Data Platform

## Sobre o projeto

Projeto de aprendizado que integra Engenharia de Dados (Data Engineering) e Ciência de Dados (Data Science), utilizando o dataset público Titanic.

O objetivo é desenvolver um pipeline de dados para ingestão, transformação, armazenamento e disponibilização de dados, seguido pelo desenvolvimento de um modelo de Machine Learning utilizando Decision Tree.

## Objetivos

- Desenvolver um pipeline de Engenharia de Dados.
- Aplicar conceitos de arquitetura Bronze, Silver e Gold.
- Implementar processos de limpeza e qualidade dos dados.
- Construir um catálogo de variáveis (Feature Catalog).
- Realizar análise exploratória de dados (EDA).
- Desenvolver um modelo de classificação supervisionada.
- Avaliar e interpretar os resultados do modelo.

## Arquitetura

O projeto será organizado em três camadas:

- **Bronze:** armazenamento dos dados originais.
- **Silver:** dados tratados e validados.
- **Gold:** produtos de dados preparados para consumo analítico e Machine Learning.

## Modelo de Machine Learning

Algoritmo inicial: Decision Tree Classifier.

Variável target: `Survived`.

- 0: Não sobreviveu.
- 1: Sobreviveu.
